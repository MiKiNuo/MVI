# 21: 证明派发、多实例与资源回收成本

**What to build:** 针对完整 v2 候选，给出可复现的派发、分配、多实例创建与释放数据，并验证规模增长时没有残留资源或订阅网络。

**Blocked by:** 20 — 切换唯一 v2 默认协议并退役旧实现。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 固定同环境、相同状态表示和等价语义的手写最小实现、归档 v1 与 v2；创建和 DI 增加标准 DI 对照，记录候选版本与测量条件。
- [ ] 复用已实现的纯转换、异步反馈、请求、Post 和并发消费场景，报告吞吐、中位和尾延迟，分开统计框架分配与业务 State 创建。
- [ ] 逐级增加独立实例与子 View 数量，覆盖创建、挂载、路由、关闭和在途释放；报告每实例内存、连接与路由规模和最终残留资源。
- [ ] 稳定泄漏、错写、丢业务事件、取消误判直接失败；跨 Feature 观察者订阅保持为零，不以框架逐字段 R3 订阅换取展示便利。
- [ ] 从固定负载建立并记录数值预算和重复测量方法；确认计时回归后定位修正并重跑有关行为与测量。预算未建立或结果未达标时不宣称完成高性能目标。
