# 22: 证明双平台交互与增量编译成本

**What to build:** 对完整 v2 的 Avalonia 和 Godot 真实界面及独立消费者编译给出可复现数据，证明更新规模增长和局部源码变更的成本符合记录的预算。

**Blocked by:** 20 — 切换唯一 v2 默认协议并退役旧实现。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 两平台运行固定真实输入、慢 IO、更新风暴、大页面与高频 HUD 负载；报告中位和尾延迟、UI 工作量及有关字段投影效果。
- [ ] 验证展示合并只影响待展示状态，不丢业务输入、定向消息、导航或提示；线程、版本与挂载/关闭仍满足功能契约。
- [ ] 测量冷构建、局部变更、无关变更和双平台消费的生成编译成本，并检查编译资产去重与诊断定位。
- [ ] 记录环境、候选版本、负载、样本、统计方法和数值预算，重复确认回归；与其他性能负载串行测量以免争用污染结论。
- [ ] 复用已有真实宿主与消费者，提交可复现命令和数据；若测量导致实现修正，重新验证受影响的功能与成本，不以成功构建或烟测替代验收。
