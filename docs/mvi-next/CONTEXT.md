# MiKiNuo.Mvi 下一版本

面向复杂业务 UI 与实时交互的 MVI 框架。业务由独立可复用的 Feature 组织，支持纯状态转换、异步业务流程与动态组合。

本词汇表适用于下一版本设计；当前代码的术语定义仍见仓库根 CONTEXT.md。

## Language

**Feature**:
可独立运行和复用的一块业务功能，具有自己的业务状态与交互流程，也可由完整的子 Feature 组成。
_Avoid_: 子 Reducer、页面类型

**Feature 实例**:
某一 Feature 的一次独立运行，拥有自己的状态、执行活动与生命周期；同类型实例之间互相独立。
_Avoid_: 业务对象 ID、全局单例

**State**:
一个 Feature 实例的不可变业务状态快照，是其状态规则与界面表达的依据；不同实例分别拥有自己的 State。
_Avoid_: ViewModel、外部业务实体

**纯状态转换**:
根据当前业务状态和输入计算新业务状态的规则，不执行 IO 或其他外部操作。
_Avoid_: 异步业务流程、副作用执行

**业务操作**:
属于某个 Feature 实例的一次业务流程，可以等待外部操作并提出业务状态变化。
_Avoid_: UI Command、EffectDispatcher

**操作运行状态**:
一次业务操作的执行状态，区分运行、结束、取消与异常；执行正常结束不代表业务结果成功。
_Avoid_: 业务状态、业务成功标志

**操作执行结果**:
一次操作调用的执行结论，区分完成、拒绝启动、取消、被取代与故障；可同时提供其业务返回值。
_Avoid_: 业务成功、UI 已绘制

**组合 Feature**:
由多个完整且独立的子 Feature 实例构成的 Feature，承担整体业务协调；子 Feature 能在其他宿主中复用。
_Avoid_: 子状态拼接、共享 Store

**Mediator**:
不同 View 及子 View 业务交互的中介，将消息路由到明确的 Feature 实例或契约端口。
_Avoid_: 全局广播总线、直接调用兄弟功能

**消息**:
通过 Mediator 向明确目标传递的业务契约，可表达操作、查询或已发生的事实。
_Avoid_: 观察者事件、广播主题

**请求**:
向一个明确目标提出操作或查询并取得处理结果的跨 Feature 契约。
_Avoid_: 广播通知、直接调用兄弟对象

**定向投递**:
将消息交给一个明确目标实例的处理入口，可以只取得接纳结果；接纳不代表业务已完成。
_Avoid_: 发布订阅、隐式分派给所有接收者

**消息接纳**:
目标实例接受一次定向消息进入自身处理流程，不表示业务已经完成。
_Avoid_: 订阅者接纳、处理成功

**请求等待结果**:
请求发起方观察到的等待结论，区分目标响应与等待被取消；取消等待不证明目标执行已经停止。
_Avoid_: 目标执行结果、回滚证明

**组合范围**:
由宿主显式建立的实例地址与契约接线边界，视图或实例嵌套不自动扩展其可见性。
_Avoid_: 视觉树、全局广播域

**View**:
Feature 的某种平台界面表达，展示状态并表达用户交互。
_Avoid_: Feature 实例、业务处理器

**实例所有者**:
管理某个 Feature 实例归属与最终生命周期的宿主；视图挂载关系不自动改变实例的业务归属。
_Avoid_: 当前 View、视觉父节点

**视图卸载**:
一次 View 展示结束，释放该视图的平台绑定和交互连接；其关联的业务实例可继续运行。
_Avoid_: 实例关闭、取消所有业务

**实例关闭**:
Feature 实例从可执行业务状态退出到最终释放资源的生命周期过程，包含逻辑关闭和资源释放完成两个阶段。
_Avoid_: 视图卸载、取消单次操作

**逻辑关闭**:
实例停止接纳新业务与迟到状态写回，并退出活动成员和通信关系；尚在退出的执行仍可能需要其资源。
_Avoid_: 资源已释放、任务已全部结束

**资源释放完成**:
实例所属执行已经真正退出，其拥有的资源已经释放；释放失败有独立结果。
_Avoid_: UI 已卸载、请求取消已发出

**关闭确认**:
对一个所有权范围是否允许关闭作出的业务判断，任一子实例拒绝时保留组合；确认条件失效时重新判断。
_Avoid_: 资源释放、已经关闭
