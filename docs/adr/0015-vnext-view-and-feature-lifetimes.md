# 下一版本分别管理 View 展示与 Feature 实例生命周期

2026-10-01 已接受，适用于下一版本设计。View 卸载释放自己的平台绑定与交互连接，Feature 实例由逻辑所有者管理，保留实例时重新挂载恢复当前状态。显式关闭实例时停止接纳新业务、请求取消在途操作并拒绝迟到结果写回；子实例关闭后移除其成员、通信与所有权关系，父组合管理自己拥有的子实例关闭。

依据 ADR 0025，平台绑定连接不构成跨 View/Feature 的观察者订阅机制。

这一选择支持 Tab 切换、独立宿主与动态多实例组合，同时要求框架明确所有权和在途资源释放规则。含未保存修改时的关闭确认、拒绝关闭后的保留行为，以及请求关闭与释放完成的契约继续在 [设计讨论](../mvi-next-design.md) 中确定。
