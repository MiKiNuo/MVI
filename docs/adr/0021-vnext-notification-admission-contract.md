# 下一版本分别定义通知接纳与处理完成

状态：已被 [ADR 0025](0025-vnext-mediator-without-observer-subscriptions.md) 替代。v2 不实现发布订阅模型；需要只接纳不等待处理的场景采用中介者定向 Post。以下保留原决策记录。

2026-10-01 已接受。请求等待目标处理结果，通知发布返回显式订阅者的接纳报告；通知采用有界接纳，实例关闭或队列已满等拒绝原因可见，接纳后的业务失败通过独立渠道观察。需要确认目标已处理或状态已提交的协作使用请求响应或明确完成协议。

这一选择保留事实通知的独立性，避免发布者等待订阅者全部业务或误把接纳当作处理成功。
