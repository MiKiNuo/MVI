# 下一版本坚持不可变状态，统一管理操作并发与运行状态

2026-10-01 已接受，适用于下一版本设计。每个 Feature 实例独立拥有不可变业务状态快照；异步操作按实例、按操作选择并发策略，默认拒绝同操作重复启动，搜索使用 Latest，需要顺序或并行执行时显式声明。Latest 请求取消旧操作，并在状态提交时检查操作有效性，避免旧结果覆盖新结果。

框架维护操作的运行、取消与异常状态，View 选择加载与错误表现；业务结果继续由纯状态转换表达，正常结束与业务成功分别定义。这一选择减少重复忙碌状态和结束处理代码，接受框架承担并发与操作追踪成本；具体完成契约和生命周期继续在 [设计讨论](../mvi-next-design.md) 中确定。
