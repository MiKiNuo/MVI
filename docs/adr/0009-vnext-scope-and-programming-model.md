# 下一版本同时支持业务 UI、实时交互与两种业务表达

2026-10-01 已接受，适用于下一版本设计。用户要求复杂业务 UI 与游戏/实时交互 UI 同等纳入目标，保留独立可复用的组合 Feature，同时支持纯状态转换与直观的异步业务流程；接受为此增加场景和验证覆盖，不能通过删除其中一种能力来简化使用方式。

交互响应、实例内存与更新成本、派发吞吐与分配、生成器与编译成本分别建立验收条件；NuGet 包结构纳入重新设计。后续已接受的运行内核、默认业务组织、动态组合与发布边界分别见 ADR 0010、0011、0012，具体执行规则继续在 [设计讨论](../mvi-next-design.md) 中收敛。
